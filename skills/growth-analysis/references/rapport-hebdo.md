# Rapport hebdomadaire de croissance — structure

## Format du rapport (persisté en kind=growth)

```markdown
# Rapport croissance <date> (<période>)

## Signaux clés
- [S1] ... (source, chiffre)
- [S2] ...

## Opportunités
- [O1] ... — cible, taille (chiffre), faisabilité, risque

## Risques
- [R1] ... (preuve)

## Actions proposées
- [A1] ... (actionnable, propriétaire)

## Sources
- outils utilisés + fichiers/mémoire
```

## Règles

- Le rapport complet est **toujours** persisté en mémoire (kind=growth) avant tout résumé.
- Le résumé Telegram (si nouveau actionnable) : 5-7 lignes, chiffres clés en tête.
- Silence si rien de nouveau (pas de spam).
- Données dégradées → synthèse partielle honnête, pas de fabrication.
