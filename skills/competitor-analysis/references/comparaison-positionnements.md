# Grille de comparaison des positionnements

## Axes fixes de comparaison

| Axe | Question | Sortie |
|---|---|---|
| **Cible** | Pour qui ? (segment, persona) | 1 phrase par concurrent |
| **Prix** | Positionnement prix (freemium, abonnement, one-shot) | fourchette ou modèle |
| **Différenciation** | Sur quoi se battent-ils ? | 1-3 éléments |
| **Force / Faiblesse** | Avantage net vs point faible | 1 phrase chacun |

## Format de sortie

Tableau concis (par concurrent) + 1 paragraphe de synthèse :
« La niche X est dominée par A (prix) mais B gagne sur Y — gap exploitable sur Z ».

## Règles

- Comparer uniquement des concurrents réellement détectés (jamais inventés).
- Chaque cellule s'appuie sur une source (veille/scan/mémoire) — pas d'impression.
- Sortie : tableau + synthèse + alertes éventuelles.
